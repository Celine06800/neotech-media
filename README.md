# neotech-media

Visuels publics de communication de Neotech Solutions (LinkedIn), servis par GitHub Pages.
Ce dépôt ne contient que des images et leurs pages sources : jamais de données de cabinet, de client ou de dossier.

- `outils/linkedin/` : charte, exemple, script de rendu et pages de chaque semaine.
- `linkedin/` : images finales utilisées dans les posts.
- `page/` : bannière de la page LinkedIn (source dans `outils/page/`).
